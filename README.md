## 🛠 Технологии
Проект написан **без использования сторонних библиотек** и фреймворков:
*   **HTML5** (семантическая разметка)
*   **CSS3** (Grid, Flexbox, CSS Variables, Media Queries)
*   **Vanilla JavaScript** (ES6+, DOM API, IntersectionObserver)
*   **Google Fonts** (шрифт Inter)

## ✨ Особенности и функционал

**CSS & Дизайн:**
*   **Смена темы:** Реализована светлая и темная тема с использованием CSS-переменных (`:root` и `.light-theme`).
*   **Адаптивность:** Сайт корректно отображается на смартфонах, планшетах и ПК (сетки перестраиваются с 4 колонок на 1).
*   **Стилизация:** Кастомные чекбоксы, карточки с hover-эффектами, плавные переходы (`transition`).

**JavaScript (Интерактивность):**
*   **Сохранение темы:** Выбор пользователя сохраняется в `localStorage` и применяется при следующей загрузке страницы.
*   **Кнопка «Наверх»:** Плавно появляется при скролле вниз и возвращает пользователя к началу страницы.
*   **Мобильное меню:** Бургер-меню для навигации на узких экранах.
*   **Анимация появления:** Секции плавно выезжают снизу при прокрутке благодаря `IntersectionObserver`.
*   **Активный пункт меню:** При скролле текущая секция автоматически подсвечивается в шапке сайта.
*   **Валидация формы:** Проверка заполнения полей и вывод сообщения об успешной отправке (без перезагрузки страницы).
